# DROP Sample Condition Number Package

<p align="center"><img src="https://github.com/lakshmiDRIP/DROP/blob/master/DRIP_Logo.gif?raw=true" width="100"></p>

DROP Sample Condition Number illustrates Condition Number Analysis of R<sup>1</sup> To R<sup>1</sup> Functions.


## Class Components

 * [***AffineR2ToR1***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/sample/conditionnumber/AffineR2ToR1.java)
 <i>AffineR2ToR1</i> illustrates the Estimation of Condition Number for Affine R<sup>2</sup> to R<sup>1</sup> Function.

 * [***OperatorFunctions***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/sample/conditionnumber/OperatorFunctions.java)
 <i>OperatorFunctions</i> illustrates the Estimation of Condition Numbers for Operator Functions.

 * [***TriangleMatrix***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/sample/conditionnumber/TriangleMatrix.java)
 <i>TriangleMatrix</i> illustrates the Estimation of Condition Number for Triangular Matrices.

 * [***TrigonometricFunctions***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/sample/conditionnumber/TrigonometricFunctions.java)
 <i>TrigonometricFunctions</i> illustrates the Estimation of Condition Numbers for Trigonometric Functions.
