# DROP Sample Gauss-Newton Package

<p align="center"><img src="https://github.com/lakshmiDRIP/DROP/blob/master/DRIP_Logo.gif?raw=true" width="100"></p>

DROP Sample Gauss-Newton Package illustrates Gauss-Newton Least-Squares Calibration.


## Class Components

 * [***MichaelisMentenGN1***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/sample/gaussnewton/MichaelisMentenGN1.java)
 <i>MichaelisMentenGN1</i> illustrates the Calibration of the Michaelis-Menten Model using the Standard Gauss-Newton Algorithm. Starting Point is {0.9, 0.2}.

 * [***MichaelisMentenGN2***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/sample/gaussnewton/MichaelisMentenGN2.java)
 <i>MichaelisMentenGN2</i> illustrates the Calibration of the Michaelis-Menten Model using the Standard Gauss-Newton Algorithm. Starting Point is {1.5, 1.5}.
