# DROP Function R<sup>1</sup> To R<sup>1</sup> Operator Package

<p align="center"><img src="https://github.com/lakshmiDRIP/DROP/blob/master/DRIP_Logo.gif?raw=true" width="100"></p>

DROP Function R<sup>1</sup> To R<sup>1</sup> Operator Package contains the Built-in R<sup>1</sup> To R<sup>1</sup> Operator Functions.


## Class Components

 * [***Addition***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/function/r1tor1operator/Addition.java)
 <i>Addition</i> implements the Univariate <code>x + a</code> Operator Function.

 * [***Convolution***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/function/r1tor1operator/Convolution.java)
 <i>Convolution</i> provides the evaluation of the Convolution <code>au1 * au2</code> and its derivatives for a specified variate.

 * [***Exponential***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/function/r1tor1operator/Exponential.java)
 <i>Exponential</i> implements the Univariate Exponential Operator Function.

 * [***Flat***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/function/r1tor1operator/Flat.java)
 <i>Flat</i> implements the level constant Univariate Function.

 * [***NaturalLogarithm***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/function/r1tor1operator/NaturalLogarithm.java)
 <i>NaturalLogarithm</i> implements the Natural Log Operator Function.

 * [***NaturalLogSeriesElement***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/function/r1tor1operator/NaturalLogSeriesElement.java)
 <i>NaturalLogSeriesElement</i> implements an element in the natural log series expansion.

 * [***OffsetIdempotent***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/function/r1tor1operator/OffsetIdempotent.java)
 <i>OffsetIdempotent</i> provides the Implementation of the Offset Idempotent Operator - f(x) = x - C.

 * [***Polynomial***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/function/r1tor1operator/Polynomial.java)
 <i>Polynomial</i> provides the evaluation of the n<sup>th</sup> order Polynomial and its derivatives for a specified variate.

 * [***Reciprocal***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/function/r1tor1operator/Reciprocal.java)
 <i>Reciprocal</i> implements the <code>1/x</code> Operator Function.

 * [***Reflection***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/function/r1tor1operator/Reflection.java)
 <i>Reflection</i> provides the evaluation f(1-x) instead of f(x) for a given f.

 * [***Scaler***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/function/r1tor1operator/Scaler.java)
 <i>Scaler</i> implements the <code>a.x</code> Operator Function.
