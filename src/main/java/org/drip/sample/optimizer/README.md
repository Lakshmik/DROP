# DROP Sample Optimizer Package

<p align="center"><img src="https://github.com/lakshmiDRIP/DROP/blob/master/DRIP_Logo.gif?raw=true" width="100"></p>

DROP Sample Optimizer demonstrates Lagrangian/KKT Necessary Sufficient Conditions.


## Class Components

 * [***Himmelblau***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/sample/optimizer/Himmelblau.java)
 <i>Himmelblau</i> illustrates the Construction and Usage of the Himmelblau Function.

 * [***KKTNecessarySufficientConditions***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/sample/optimizer/KKTNecessarySufficientConditions.java)
 <i>KKTNecessarySufficientConditions</i> carries out the Zero and the First Order Necessary and the Second Order Sufficiency Checks for a Constrained KKT Optimization Problem.

 * [***KKTRegularityConditions***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/sample/optimizer/KKTRegularityConditions.java)
 <i>KKTRegularityConditions</i> carries out the Regularity Checks satisfied by the Optimizing Variate for a Constrained KKT Optimization Problem.

 * [***MultidimensionalCoupledRosenbrockFunction***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/sample/optimizer/MultidimensionalCoupledRosenbrockFunction.java)
 <i>MultidimensionalCoupledRosenbrockFunction</i> illustrates the Construction and Usage of the Multidimensional Coupled 2D Rosenbrock Function.

 * [***MultidimensionalUncoupledRosenbrockFunction***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/sample/optimizer/MultidimensionalUncoupledRosenbrockFunction.java)
 <i>MultidimensionalUncoupledRosenbrockFunction</i> illustrates the Construction and Usage of the Multidimensional Uncoupled 2D Rosenbrock Function.

 * [***NelderMeadRosenbrock3Coupled***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/sample/optimizer/NelderMeadRosenbrock3Coupled.java)
 <i>NelderMeadRosenbrock3Coupled</i> illustrates the Optimization of Multidimensional Three Coupled 2D Rosenbrock Function using the Nelder Mead Scheme.

 * [***NelderMeadRosenbrock4Coupled***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/sample/optimizer/NelderMeadRosenbrock4Coupled.java)
 <i>NelderMeadRosenbrock4Coupled</i> illustrates the Optimization of Multidimensional Four Coupled 2D Rosenbrock Function using the Nelder Mead Scheme.

 * [***NelderMeadRosenbrock5Coupled***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/sample/optimizer/NelderMeadRosenbrock5Coupled.java)
 <i>NelderMeadRosenbrock5Coupled</i> illustrates the Optimization of Multidimensional Five Coupled 2D Rosenbrock Function using the Nelder Mead Scheme.

 * [***NelderMeadRosenbrock6Coupled***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/sample/optimizer/NelderMeadRosenbrock6Coupled.java)
 <i>NelderMeadRosenbrock6Coupled</i> illustrates the Optimization of Multidimensional Six Coupled 2D Rosenbrock Function using the Nelder Mead Scheme.

 * [***NelderMeadRosenbrock7Coupled***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/sample/optimizer/NelderMeadRosenbrock7Coupled.java)
 <i>NelderMeadRosenbrock7Coupled</i> illustrates the Optimization of Multidimensional Seven Coupled 2D Rosenbrock Function using the Nelder Mead Scheme.

 * [***NSphereSurfaceExtremization***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/sample/optimizer/NSphereSurfaceExtremization.java)
 <i>NSphereSurfaceExtremization</i> computes the Equality-Constrained Extrema of the Specified Function along the Surface of an N-Sphere using Lagrange Multipliers.

 * [***Rosenbrock***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/sample/optimizer/Rosenbrock.java)
 <i>Rosenbrock</i> illustrates the Construction and Usage of the Rosenbrock Function.

 * [***VariateArrayIterator***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/sample/optimizer/VariateArrayIterator.java)
 <i>VariateArrayIterator</i> illustrates the Construction and Usage of the Exhaustive Variate Array Iterator.

 * [***VariateSumExtremization***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/sample/optimizer/PhaseTrackerComparison.java)
 <i>VariateSumExtremization</i> computes the Equality Constrained Extrema of the Sum of Variates VariateSumExtremization the Surface of the Sphere using Lagrange Multipliers.
