# DROP Function R<sup>1</sup> To R<sup>1</sup> Trigonometric Package

<p align="center"><img src="https://github.com/lakshmiDRIP/DROP/blob/master/DRIP_Logo.gif?raw=true" width="100"></p>

DROP Function R<sup>1</sup> To R<sup>1</sup> Trigonometric Package contains the Built-in R<sup>1</sup> To R<sup>1</sup> Trigonometric Functions.


## Class Components

 * [***Cosine***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/function/r1tor1trigonometric/Cosine.java)
 <i>Cosine</i> implements the Trigonometric Cosine Function.

 * [***InverseCosine***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/function/r1tor1trigonometric/InverseCosine.java)
 <i>InverseCosine</i> implements the Trigonometric Inverse Cosine Function.
 
 * [***InverseSine***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/function/r1tor1trigonometric/InverseSine.java)
 <i>InverseSine</i> implements the Trigonometric Inverse Sine Function.
  
 * [***InverseTangent***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/function/r1tor1trigonometric/InverseTangent.java)
 <i>InverseTangent</i> implements the Trigonometric Inverse Tangent Function.
  
 * [***Sinc***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/function/r1tor1trigonometric/Sinc.java)
 <i>Sinc</i> computes the Pi Z-Scaled Reciprocal of the Sine Function of Pi times the Argument.
  
 * [***Sine***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/function/r1tor1trigonometric/Sine.java)
 <i>Sine</i> implements the Trigonometric Sine Function.
  
 * [***Tangent***](https://github.com/lakshmiDRIP/DROP/tree/master/src/main/java/org/drip/function/r1tor1trigonometric/Tangent.java)
 <i>Tangent</i> implements the Trigonometric Tangent Function.
